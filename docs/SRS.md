# وثيقة مواصفات متطلبات البرمجيات (SRS)

## 1. معلومات المشروع

| البند | القيمة |
|---|---|
| الاسم | مِداد \| MIDAD |
| نوع المنتج | تطبيق ويب عربي تفاعلي للاقتباسات والشعر |
| التقنية | Laravel 12، Blade، Eloquent، SQLite افتراضيًا |
| نسخة المواصفات | التسليم النهائي — 28 أكتوبر 2026 |

## 2. الغرض والنطاق

تتيح مِداد للزوار قراءة الاقتباسات المنشورة، وللمستخدمين المسجلين مشاركة اقتباسات قصيرة وإدارة اقتباساتهم والتفاعل مع محتوى المجتمع. يتضمن الموقع أيضًا ملفات عامة، دليل الشعراء، المعلقات، الإشعارات، التعليقات والمتابعة. لا تدخل القصائد الطويلة في نموذج الإدخال المخصص لاقتباسات المجتمع، ولا تُحذف سجلاتها القديمة.

## 3. أنواع المستخدمين

| النوع | الصلاحيات |
|---|---|
| زائر | تصفح الرئيسية والمكتبة العامة، البحث والتصفية، فتح الاقتباس والملفات العامة، بدء التسجيل أو الدخول |
| مستخدم مسجل | جميع صلاحيات الزائر، وإضافة اقتباس 3–155 حرفًا، وتعديل/حذف اقتباساته فقط، والإعجاب والحفظ والتعليق والمتابعة وإدارة ملفه |
| مشرف | صلاحيات الإدارة الإضافية المعرفة في التطبيق، ومنها إدارة المحتوى عبر لوحة الإدارة |

## 4. المتطلبات الوظيفية

| الرمز | المتطلب | تحقق التنفيذ |
|---|---|---|
| FR-01 | عرض الاقتباسات المنشورة لجميع الزوار مع نص الاقتباس واسم الناشر وتاريخ النشر | الرئيسية تعرض أحدث خمسة؛ `/quotes` يعرض المكتبة بترقيم صفحات |
| FR-02 | إنشاء حساب باسم 2–50 حرفًا، وبريد صحيح وفريد، وكلمة مرور 8 أحرف فأكثر مع التأكيد | تحقق خادمي في `AuthController`، وقيود إرشادية في نموذج التسجيل |
| FR-03 | تسجيل الدخول بالبريد وكلمة المرور، مع دعم اسم المستخدم السابق للتوافق | `AuthController@login` يستخدم `Auth::attempt` |
| FR-04 | تمكين المستخدم من تسجيل الخروج | POST محمي عبر وسيط `auth` مع إبطال الجلسة وتجديد CSRF token |
| FR-05 | نشر اقتباس بواسطة مستخدم مسجل، بطول 3–155 حرفًا | وسيط `auth` وقواعد Laravel في `QuoteController@store` وقيود HTML وعداد أحرف |
| FR-06 | تعديل اقتباس المالك فقط، مع حد الطول نفسه | `QuotePolicy`، وسيط `can:update`، وتحقق `QuoteController@update` |
| FR-07 | حذف اقتباس المالك فقط | `QuotePolicy` ووسيط `can:delete`؛ حذف المشرف الإداري مسار إدارة مستقل محفوظ |
| FR-08 | البحث في النص والكاتب والمصدر والتصفية حسب التصنيف | GET `/quotes?q=&category=` |
| FR-09 | ترقيم صفحات 12 سجلًا مع الاحتفاظ بمدخلات البحث والتصنيف | `paginate(12)->withQueryString()` |
| FR-10 | الإعجاب بالاقتباس وحفظه للمستخدم | جداول `quote_likes` و`quote_favorites` بعلاقات ومفاتيح فريدة لكل مستخدم/اقتباس |
| FR-11 | عرض الاقتباس الكامل وصفحة تفاصيله وتعليقاته | مسار `quotes.show` مع eager loading لصاحب التعليق والاقتباس |

## 5. المتطلبات غير الوظيفية

| الرمز | المتطلب | آلية التنفيذ/التحقق |
|---|---|---|
| NFR-01 الأمان | تخزين كلمة المرور كتجزئة | cast `password => hashed` في `User`، ويختبر التحقق بـ `Hash::check` |
| NFR-02 التفويض | منع تعديل/حذف اقتباس مستخدم آخر حتى مع طلب مباشر | سياسة `QuotePolicy` وHTTP 403، مع اختبار طلب PUT وDELETE من مستخدم آخر |
| NFR-03 سهولة الاستخدام | إرشادات طول الاسم وكلمة المرور والاقتباس وعداد أحرف | مكوّن `x-form-field` وعداد حي، وتحويل المسجل الجديد مباشرة إلى نموذج الإضافة |
| NFR-04 الأداء | eager loading وعلاقات محسوبة بدل استعلامات داخل الحلقات | `with('user')`, `withCount`, `withExists`; قائمة محدودة إلى 12 سجلًا في الصفحة |
| NFR-05 الأداء | فهرسة ترتيب الأحدث | فهرس مركب على `quotes(created_at, id)` إضافة إلى فهرس التصنيف/التاريخ الموجود |
| NFR-06 التوافق | واجهة RTL واستجابة للجوال وسطح المكتب | قوالب عربية وCSS responsive؛ يجب توثيق فحص المتصفح الفعلي عند التسليم |
| NFR-07 سلامة المحتوى | عدم قصّ أو حذف النصوص القديمة الطويلة | لا توجد قيود DB تقص النص؛ حد الطول يخص الإنشاء والتعديل الجديدين فقط |

## 6. الميزة الإضافية المعتمدة

**الإعجاب والحفظ والبحث/التصفية** هي الميزات الإضافية المعتمدة. تسجل الإعجابات في `quote_likes` والحفظ في `quote_favorites` مع FK إلى المستخدم والاقتباس وقيد uniqueness يمنع تكرار تفاعل المستخدم نفسه. البحث والتصنيف يعملان من قاعدة البيانات، وتحتفظ روابط الترقيم بقيم الفلاتر.

## 7. قرار المحتوى الطويل

لا يوجد جدول مستقل للقصائد أو المعلقات في migrations الحالية. الاقتباسات والنصوص القديمة محفوظة في `quotes.text` من نوع `TEXT`، وقد أظهر فحص قاعدة التطوير وجود 9 سجلات أطول من 155 حرفًا. لم تُعدّل هذه السجلات ولم تُقص. يمكن عرضها كاملة في صفحاتها؛ أما تعديلها عبر نموذج اقتباس المستخدم فيتطلب نصًا جديدًا ضمن 3–155 حرفًا. فصل الشعر الطويل في كيان مستقل قرار ترحيل مستقبلي يحتاج موافقة مالك المشروع وخطة نقل بيانات، لذلك لم يُنفذ هنا.

## 8. قرار قاعدة البيانات

لم تُغيّر جداول الإنتاج أو بياناتها. أُضيف migration غير هدّام لفهرس ترتيب أحدث الاقتباسات. يظل عمود `user_id` nullable للتوافق مع السجلات القديمة، بينما لا يمكن إنشاء اقتباس جديد إلا بعد الدخول ويُسند إلى المستخدم الحالي من الخادم.

## 9. تغييرات التسليم

- إضافة صفحة `/quotes` مستقلة ببحث وتصنيف وترقيم صفحات.
- حصر الرئيسية على آخر خمسة اقتباسات واستخدام مكوّن بطاقة مشترك.
- إضافة مسارات الإنشاء والتعديل والحذف مع سياسة ملكية خادمية.
- ضبط حدود التسجيل والاقتباس وإرشادات النماذج وعداد الحروف.
- إبقاء الإعجاب والحفظ وسائر الميزات الحالية، ومنع seeder من إنشاء محتوى تجريبي.
- إنشاء ERD من ملفات migrations الفعلية؛ راجع `docs/ERD.mmd`.

## 10. خطة القبول

اختبارات feature تغطي مدخلات التسجيل، حدود الاقتباس 2 و155 و156 حرفًا، إنشاء/تعديل/حذف الاقتباس، رفض المالك غير الصحيح، الصفحة العامة، الترقيم مع الفلاتر، وتخزين الإعجاب والحفظ. زمن الاستجابة يقاس على بيئة التشغيل المحلية باستخدام طلب HTTP مؤقت. قياس 390px و1440px يتطلب متصفحًا بأدوات responsive؛ لا يُسجل كاختبار منفذ ما لم يُنفذ فعليًا.
