## 1. المقدمة

### 1.1 الغرض
توثّق هذه الوثيقة المتطلبات الوظيفية وغير الوظيفية لمنصة «مِداد»، وهي تطبيق ويب عربي يتيح للزوار تصفح الاقتباسات، وللمستخدمين المسجلين نشر اقتباساتهم وإدارتها والتفاعل معها.

### 1.2 النطاق
- عرض عام لكل الاقتباسات المنشورة مع اسم الناشر وتاريخ النشر.
- إنشاء حساب، تسجيل دخول، تسجيل خروج.
- نشر اقتباس (3–155 حرفًا)، وتعديله وحذفه من قِبل صاحبه فقط.
- ميزة إضافية: الإعجاب والحفظ (المفضلة)، مدعومة بالبحث والتصفية حسب التصنيف.
- محتوى أدبي ثابت: دليل الشعراء والمعلّقات السبع (من ملفات إعداد، خارج جدول الاقتباسات).

### 1.3 التعريفات
| المصطلح | المعنى |
|---|---|
| الناشر | صاحب الحساب الذي أضاف الاقتباس (`quotes.user_id`) |
| القائل | اسم الشاعر أو الكاتب صاحب الكلمات (`quotes.author`)، اختياري |
| الاقتباس القديم الطويل | سجل محفوظ قبل تطبيق حد 155 حرفًا، يبقى كما هو |

## 2. أنواع المستخدمين

| النوع | الصلاحيات |
|---|---|
| **زائر** | تصفح الرئيسية (أحدث 5 اقتباسات) وصفحة كل الاقتباسات، البحث والتصفية، فتح تفاصيل الاقتباس، صفحات الشعراء والمعلّقات والملفات العامة، إنشاء حساب أو تسجيل الدخول |
| **مستخدم مسجّل** | كل صلاحيات الزائر، إضافة اقتباس، تعديل وحذف اقتباساته فقط، الإعجاب والحفظ والتعليق والمتابعة، صفحة المفضلة، الإشعارات، تعديل ملفه الشخصي، تسجيل الخروج |
| مشرف (موجود مسبقًا) | لوحة إدارة لمتابعة المحتوى وحذف المخالف — خارج متطلبات الدليل وأُبقي دون تغيير |

## 3. المتطلبات الوظيفية

| الرمز | المتطلب | التنفيذ |
|---|---|---|
| FR-01 | عرض الاقتباسات لكل المستخدمين بما فيهم الزوار، مع النص واسم الناشر وتاريخ النشر | مسارات عامة `/` و`/quotes` و`/quotes/{id}`؛ مكوّن `x-quote-card` يعرض النص والناشر والتاريخ |
| FR-02 | الرئيسية تعرض أحدث 5 اقتباسات فقط مع زر «عرض كل الاقتباسات» | استعلام محدود `take(5)` مرتب من الأحدث |
| FR-03 | صفحة كل الاقتباسات: الأحدث أولًا، 12 في الصفحة، عدد الاقتباسات، زر الإضافة | `paginate(12)->withQueryString()` |
| FR-04 | إنشاء حساب: الاسم 2–50 حرفًا، بريد صحيح غير مكرر، كلمة مرور 8 أحرف على الأقل مع التأكيد | `AuthController@register` + رسائل عربية بجانب كل حقل |
| FR-05 | تسجيل الدخول بالبريد الإلكتروني وكلمة المرور | `AuthController@login` باستخدام `Auth::attempt` |
| FR-06 | تسجيل الخروج | `POST /logout` مع إبطال الجلسة وتجديد رمز CSRF |
| FR-07 | مشاركة اقتباس للمستخدم المسجّل فقط، بطول 3–155 حرفًا (عميل + خادم) | وسيط `auth`، `QuoteRequest` (min:3, max:155)، `minlength/maxlength` وعدّاد أحرف حي |
| FR-08 | تعديل الاقتباس لصاحبه فقط | `QuotePolicy@update` على المسار (`can:update`) |
| FR-09 | حذف الاقتباس لصاحبه فقط | `QuotePolicy@delete` على المسار (`can:delete`) |
| FR-10 | البحث في النص والقائل والمصدر، والتصفية حسب التصنيف، مع زر مسح | `GET /quotes?q=&category=`؛ روابط الترقيم تحتفظ بالقيم |
| FR-11 | الإعجاب بالاقتباس وإلغاؤه | `POST /quotes/{id}/like` (AJAX)، جدول `quote_likes` |
| FR-12 | حفظ الاقتباس في المفضلة وإزالته، وصفحة «مفضلتي» | `POST /quotes/{id}/favorite`، جدول `quote_favorites`، `/favorites` |
| FR-13 | نسخ الاقتباس ومشاركة رابطه | أزرار في البطاقة (Clipboard / Web Share API) |

## 4. المتطلبات غير الوظيفية

| الرمز | الفئة | المتطلب | التنفيذ والتحقق |
|---|---|---|---|
| NFR-01 | الأمان | تخزين كلمات المرور مشفّرة | cast `password => hashed` (bcrypt)؛ كل السجلات تبدأ بـ `$2y$`؛ اختبار `Hash::check` |
| NFR-02 | الأمان | منع تعديل/حذف اقتباس مستخدم آخر حتى بطلب يدوي | `QuotePolicy` على مستوى المسار ← HTTP 403؛ اختبار GET/PUT/DELETE من مستخدم آخر |
| NFR-03 | الأمان | حماية النماذج والاستعلامات | `@csrf` في كل نموذج، تحقق خادمي، ربط معاملات Eloquent، تحديد معدل الطلبات للدخول والتسجيل والنشر |
| NFR-04 | سهولة الاستخدام | تلميح قصير تحت كل حقل | «من 2 إلى 50 حرفًا»، «8 أحرف على الأقل»، «من 3 إلى 155 حرفًا» عبر `x-form-field` |
| NFR-05 | سهولة الاستخدام | تسجيل ومشاركة أول اقتباس خلال دقيقة | بعد التسجيل ينتقل المستخدم مباشرة إلى نموذج الإضافة |
| NFR-06 | سهولة الاستخدام | رسائل خطأ عربية واضحة بجانب الحقول | `lang/ar/validation.php` |
| NFR-07 | الأداء | تحميل صفحة الاقتباسات خلال 3 ثوانٍ | eager loading عبر `Quote::withCardData()`، ترقيم 12، فهارس؛ القياس المحلي: وسيط استجابة الخادم 0.24 ث، وتحميل كامل في المتصفح 0.33–0.43 ث |
| NFR-08 | الأداء | لا استعلامات داخل الحلقات | اختبار يثبت أن عدد الاستعلامات ثابت مع 3 أو 23 اقتباسًا |
| NFR-09 | التوافق | واجهة RTL متجاوبة دون تمرير أفقي | فحص فعلي على 390px و1440px لعشر صفحات: لا تمرير أفقي |
| NFR-10 | سلامة البيانات | عدم حذف أو قص المحتوى القديم | لا قيود قاعدة بيانات تقص النص؛ حد الطول على الإنشاء والتعديل فقط |

## 5. الميزة الإضافية: الإعجاب والحفظ

- **الإعجاب**: جدول `quote_likes` (quote_id, user_id) بمفاتيح أجنبية `cascadeOnDelete` وقيد فريد مركّب يمنع تكرار إعجاب المستخدم نفسه. التبديل يتم داخل معاملة مقفلة، ويحدّث العدّاد دون إعادة تحميل الصفحة.
- **الحفظ (المفضلة)**: جدول `quote_favorites` بالبنية والقيود نفسها، وصفحة «مفضلتي» مرتبة حسب وقت الحفظ.
- **البحث والتصفية**: يعملان على قاعدة البيانات مباشرة، مع الحفاظ على حالتهما عبر صفحات الترقيم.
- تظهر حالة الإعجاب والحفظ بالمنطق نفسه في الرئيسية وصفحة الاقتباسات والمفضلة والملف الشخصي وصفحة القائل، لأنها جميعًا تستخدم مكوّن البطاقة نفسه.

---

## 6. واجهة المستخدم وBlade

- كل الصفحات ترث القالب `layouts/app.blade.php` عبر `@extends` و`@section`.
- مكوّنات Blade للعناصر المتكررة: `x-site-header`، `x-site-footer`، `x-quote-card` (بطاقة واحدة لكل القوائم)، `x-quote-fields` (حقول الاقتباس في الإضافة والتعديل ونافذة الإضافة السريعة)، `x-form-field`، `x-button`.
- ترقيم صفحات عربي بهوية الموقع (`pagination/midad.blade.php`).
- النصوص الطويلة تُختصر بصريًا (line-clamp) مع «قراءة المزيد» دون تعديل النص المخزّن.

## 7. قاعدة البيانات

الجداول الأساسية: `users`، `quotes`، `quote_likes`، `quote_favorites`، إضافة إلى `quote_comments`، `user_follows`، `user_notifications`، `special_profile_messages` وجداول Laravel القياسية. انظر مخطط ERD المرفق (`Abdulaziz_ERD.pdf`) المستخرج من ملفات migrations الفعلية.

| الجدول | الفهارس والقيود |
|---|---|
| `users` | `email` فريد، `username` فريد |
| `quotes` | FK `user_id` (nullable، nullOnDelete)، فهرس `(category, created_at)`، فهرس `(created_at, id)` |
| `quote_likes` / `quote_favorites` | FK إلى المستخدم والاقتباس مع cascade، قيد فريد `(quote_id, user_id)` |

---

## 8. قرار المحتوى الطويل

- المعلّقات السبع (`config/muallaqat.php`) وأبيات الشعراء المختارين (`config/featured_poets.php`) منفصلة عن قاعدة البيانات، ولا يخضع لها حد 155 حرفًا.
- في جدول `quotes` تسعة سجلات قديمة أطول من 155 حرفًا (159–433). بقرار من مالك المشروع **بقيت كما هي** دون حذف أو قص: تُعرض كاملة في صفحة التفاصيل ومختصرة بصريًا في البطاقات.
- عند فتح أحدها للتعديل يظهر تنبيه بأن الحفظ يتطلب اختصار النص إلى 155 حرفًا أو أقل.

## 9. التغييرات في هذا الإصدار

| المجال | التغيير |
|---|---|
| اللغة | تفعيل اللغة العربية (`APP_LOCALE=ar`) ورسائل تحقق عربية؛ التواريخ النسبية بالعربية («منذ 3 أيام») |
| العرض | ترقيم صفحات عربي بهوية الموقع؛ «قراءة المزيد» تظهر فقط عند اختصار النص فعلًا |
| النماذج | أخطاء كلمة المرور والدخول تظهر بجانب الحقل؛ مكوّن `x-quote-fields` موحّد |
| المكوّنات | صفحات المفضلة والملف الشخصي وصفحة القائل صارت تستخدم `x-quote-card` |
| الخادم | `QuoteRequest` لقواعد الاقتباس؛ `Quote::withCardData()`؛ علاقات الإعجاب والحفظ في النماذج؛ تبديل الحفظ داخل معاملة مقفلة |
| قاعدة البيانات | تطبيق فهرس `quotes_latest_index` (إضافة فهرس فقط، دون تعديل بيانات) |
| الجودة | إصلاح تشغيل الاختبارات؛ 40 اختبارًا آليًا ناجحًا |
