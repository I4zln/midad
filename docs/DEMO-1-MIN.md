# سيناريو عرض مِداد — 60 ثانية

| الوقت | العرض والتعليق |
|---|---|
| 0–8 ث | افتح `/quotes` كزائر. أظهر ترتيب الأحدث والبحث والتصنيفات، ثم افتح اقتباسًا. «يمكن للجميع تصفح مكتبة مِداد.» |
| 8–17 ث | افتح إنشاء الحساب، أدخل اسمًا وبريدًا وكلمة مرور، ثم أرسل النموذج. «يُنشأ الحساب وتنتقل مباشرة إلى إضافة أول اقتباس.» |
| 17–28 ث | اكتب اقتباسًا بين 3 و155 حرفًا، وأظهر عداد الأحرف، ثم انشره. ارجع للرئيسية وأظهر ظهوره في أعلى الأحدث. |
| 28–39 ث | افتح تفاصيل الاقتباس واختر «تعديل الاقتباس»، غيّر النص واحفظ. أظهر النص المحدث. |
| 39–47 ث | احذف الاقتباس من صفحة التعديل، وأكد الحذف. أظهر عودتك إلى المكتبة. |
| 47–60 ث | سجّل بحساب مستخدم ثانٍ أو استخدم اقتباسًا عامًا: أظهر الإعجاب والحفظ، ثم افتح صفحة المفضلة أو استخدم البحث والتصنيف مع الترقيم. «الإعجاب والحفظ والبحث ميزات موصولة بقاعدة البيانات.» |

**تنبيه تصوير:** نفّذ العرض بقاعدة عرض مخصصة وبحسابين تملكهما. لا تستخدم قاعدة الإنتاج أو بيانات أشخاص حقيقيين أثناء التسجيل.
