# سيناريو فيديو العرض — دقيقة واحدة

**قبل التصوير:** استخدم قاعدة بيانات عرض (`php artisan migrate:fresh --seed` على نسخة منفصلة) وبريدًا تجريبيًا تملكه. لا تُظهر ملف `.env` ولا بيانات أشخاص حقيقيين.

| الوقت | ما يظهر على الشاشة | التعليق الصوتي |
|---|---|---|
| 0–8 ث | الرئيسية كزائر: قسم «أحدث الاقتباسات» (5 بطاقات) ثم زر «عرض كل الاقتباسات» | «هذه مِداد، منصة عربية للاقتباسات. يرى أي زائر أحدث خمسة اقتباسات، باسم الناشر وتاريخ النشر.» |
| 8–15 ث | صفحة `/quotes`: العدد، الترقيم، بحث بكلمة واختيار تصنيف ثم الانتقال للصفحة 2 | «وهنا كل الاقتباسات من الأحدث، مع بحث وتصنيف يبقيان مع الترقيم.» |
| 15–25 ث | «أنشئ حسابًا»: أدخل اسمًا من حرف واحد لإظهار الخطأ العربي، ثم صحّحه وأكمل البريد وكلمة المرور | «التسجيل يتحقق من الاسم والبريد وكلمة المرور، والرسائل واضحة بجانب كل حقل.» |
| 25–35 ث | يُنقل مباشرة إلى «أضف اقتباسًا»: اكتب نصًا وأظهر عدّاد الأحرف (… / 155) ثم انشر؛ يظهر أولًا في الرئيسية | «بعد التسجيل أشارك اقتباسي الأول فورًا، ويظهر أولًا في الرئيسية.» |
| 35–43 ث | افتح الاقتباس ← «تعديل الاقتباس» ← غيّر كلمة واحفظ | «يمكنني تعديل اقتباسي فقط؛ الخادم يرفض أي محاولة على اقتباس غيري.» |
| 43–50 ث | «حذف الاقتباس» ← أكّد | «وحذفه كذلك متاح لصاحبه فقط.» |
| 50–60 ث | على اقتباس آخر: اضغط «إعجاب» (يتغير العدد فورًا) ثم «حفظ»، وافتح «مفضلتي» | «الميزة الإضافية: الإعجاب والحفظ، محفوظان في قاعدة البيانات، مع صفحة لمفضلتي.» |
